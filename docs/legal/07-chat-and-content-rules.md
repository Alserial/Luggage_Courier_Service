# Kargo 站内沟通与内容规则（法务审核草案）

> 草案版本：`2026-08-22-draft.1`

## 1. 使用范围

站内聊天仅用于已成立订单的物品核对、交接、行程、送达、异常和争议沟通。初版仅支持文字；物品、证件、交接、航班、海关和送达文件应通过证据上传功能提交。

## 2. 留存与安全检查提示

1. 消息由平台保存并进行自动或人工安全检查，可用于履约核对、风险审核、举报和争议处理。
2. 普通用户消息不可编辑、覆盖或物理删除；管理员隐藏不改变历史消息和既有证据快照。
3. 平台可生成带有消息编号、时间范围和内容哈希的不可变聊天证据快照。
4. 保存期限和个人信息权利按隐私政策执行。

## 3. 禁止内容

用户不得发送：

- 手机号、微信号、二维码或其他用于绕开平台的联系方式；
- 站外服务费、商品货款、押金或其他私人支付指引；
- 禁限物品协商、盲带请求、藏匿方法、虚假申报或规避安检内容；
- 欺诈、钓鱼、洗钱、走私或其他违法活动；
- 威胁、骚扰、歧视、仇恨、色情、暴力或人身攻击；
- 他人的身份证件、金融账号、精确住址或其他无关个人信息；
- 恶意广告、垃圾信息、病毒链接或侵犯知识产权的内容；
- 伪造平台、主管机关、航空公司或支付服务商身份的内容。

## 4. 内容处理

平台可以根据内容和风险采取：

- 阻止发送并给出安全提示；
- 标记 `under_review`，在人工审核前暂不展示；
- 在双方页面隐藏但保留后台审计；
- 限制聊天、发布、报价或订单能力；
- 对紧急安全风险采取账号限制并依法报告。

平台应尽量使用稳定、可理解的理由说明处理结果，不向普通用户公开攻击规则、内部风控阈值或他人敏感信息。

## 5. 举报与复核

1. 订单参与方可以举报外部联系、站外支付、禁限物品、骚扰、欺诈或垃圾信息。
2. 第三方不得访问或举报不属于其订单的消息。
3. 管理员的隐藏、恢复或驳回操作必须记录人员、理由、目标和时间。
4. 被采取不利措施的用户可申请人工复核；平台应告知主要事实、理由和规则依据。

## 6. 证据提醒

仅有聊天文字通常不足以证明物品状态、付款、交接或送达。双方应使用平台证据入口形成对应的物品照片、交接码、支付记录、官方证明、送达照片或双方确认。

## 7. 紧急和违法内容

存在人身安全、诈骗、走私、禁品或其他紧急风险时，用户应立即停止交接和携带，并联系当地警方、海关、机场或航空公司。平台可依法保存和向有权机关提供相关记录。
