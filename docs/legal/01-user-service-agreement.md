## 1. 协议范围与接受

1. 本协议约定用户与 Kargo 运营主体之间关于注册、访问和使用 Kargo 微信小程序及相关服务的权利义务。
2. 《隐私政策》《平台交易与履约规则》《物品正面清单与申报规则》《服务费、取消与退款规则》《证据与争议处理规则》《站内沟通与内容规则》以及与具体路线对应的中国、澳大利亚进出境附件，均为本协议组成部分。
3. 用户应在注册或首次登录前主动勾选同意本协议和隐私政策。平台不得默认勾选或者以误导方式取得同意。
4. 涉及收费、退款、海关申报、责任限制、证据使用和争议解决的重大条款，平台应另行显著提示；用户可要求平台解释。
5. 用户不同意非必要个人信息处理的，平台不得因此拒绝其使用不依赖该信息的基础浏览功能。

## 2. 用户资格与账号

1. 本受控 MVP 仅向年满 18 周岁、具有完全民事行为能力并能够独立承担出入境申报责任的自然人开放。
2. 用户作为携带人提供有偿服务前，必须确保其身份、签证、工作权、税务和其他资格允许其在出发地、目的地及实际履约地提供该服务；工作权不明确的不得发布行程或接受报价。
3. 用户应使用本人微信身份注册，不得冒用、转让、出租或出借账号。
4. 发布信息、提供站内沟通等依法需要真实身份认证的功能，在完成平台要求的认证前可以被限制。
5. 用户应保持联系方式和认证资料真实、准确、有效，并妥善保护账号和设备。
6. 用户发现账号被未经授权使用，应立即通过本协议所列渠道通知平台。

## 3. 平台服务性质

1. Kargo 仅提供低值、低频、低风险个人小件的信息发布、路线匹配、报价、订单记录、证据留存、站内沟通和争议流程工具。
2. 除非另有书面明确约定，平台不是：
   - 商品的卖方、买方或代购方；
   - 承运人、快递企业、货运代理或报关行；
   - 海关、检疫、航空安全或移民咨询机构；
   - 保险人或保证送达、保证清关、保证免税的一方；
   - 商品货款托管方或跨境支付服务商。
3. 平台审核、标签、匹配分数或者“已通过”状态仅表示符合平台当时的受控试点规则，不表示任何政府机关或航空公司已经批准该物品。
4. 平台依法应承担的责任不因本条而被排除或不合理减轻。

## 4. 用户角色与共同义务

### 4.1 需求方

需求方应当：

- 对物品享有合法所有权、占有权或者明确授权；
- 如实披露名称、品牌、数量、成分、用途、来源、购买价格、申报价值、重量、尺寸、电池或液体属性；
- 提供真实物品照片和必要凭证；
- 不得要求携带人盲带、隐藏、夹带、拆分规避限额或虚假申报；
- 按约定承担服务费以及依法由其承担的税费、退运、销毁或处理费用，但因携带人故意违法、擅自替换或虚假申报造成的除外；
- 在交接时允许携带人在合理范围内开箱核对。

### 4.2 携带人

携带人应当：

- 发布真实行程并在订单确认前完成平台要求的行程核验；
- 亲自检查物品和包装，确认自己知道行李内全部内容；
- 独立核对出境国、入境国、经停地、航空公司和机场规则；
- 对边境申报、旅客卡、安检问询和行李内容作真实、完整回答；
- 不接受无法开箱、无法识别、信息不一致、需要许可但没有有效文件或者超出个人行李边界的物品；
- 不得擅自使用、替换、转交、出售或处分物品；
- 出现查验、延误、税费、扣留、退运或损坏时及时站内通知并保留官方证明。

### 4.3 双方共同义务

- 遵守中国、澳大利亚、经停地和承运航空公司的全部适用规定；
- 在平台内完成报价、条款确认、交接、送达、异常和争议留痕；
- 不交换站外支付指引，不以平台订单掩盖商业贸易、代购、走私或其他违法活动；
- 配合平台依法开展身份、物品、内容、安全和争议审核。

## 5. 发布、报价与订单成立

1. 需求或行程发布不构成平台对交易的承诺，也不当然构成双方合同。
2. 携带人报价应仅包含帮带服务费及明确列出的条件，不得包含商品货款。
3. 需求方接受报价并完成重大条款确认后，双方之间的帮带服务订单成立，订单状态进入 `pending_payment`。
4. 系统错误、重复提交、身份或权限异常、需求未审核、行程未核验、物品信息重大不实等情形下，平台可拒绝创建或撤销尚未履行的订单，并说明理由。
5. 订单成立后，双方不得通过私下修改聊天内容替代订单字段；变更路线、物品、金额、日期或责任安排，应通过平台支持的变更、取消或重新下单流程完成。

## 6. 费用、税费与商品货款

1. 平台当前只记录帮带服务费和平台服务费，不处理商品购买价款。
2. 当前仓库中的支付为 Mock 占位，不代表真实资金已经收取、托管、分账、结算或退款。
3. 启用真实支付前，平台应另行公示支付服务商、收费标准、结算条件、退款方式和发票安排，并取得必要确认。
4. 主管机关征收的关税、GST、增值税、消费税、检疫处理费、仓储、退运或销毁费用，以主管机关决定为准。平台默认规则不得对抗法律或主管机关决定。
5. 双方不得把服务费表述为购买商品的货款、保险费或清关保证金。

## 7. 出入境与航空安全

1. 用户必须同时满足出境地、入境地、经停地和航空公司的要求；满足其中一地规则不代表可以完成整段行程。
2. 有偿替他人携带物品可能不符合“自用合理”、个人物品、旅客免税优惠或个人行李条件。平台不作相反保证。
3. 如主管机关或航空公司要求以货物申报、商业进口、许可、检疫证明或专业危险品运输方式办理，该物品不得继续使用本平台普通旅客行李流程。
4. 对规则不确定的物品，用户应在交接前向主管机关和航空公司确认；无法取得明确依据的，应取消或拒绝订单。

## 8. 交接、履约与证据

1. 交接应当在双方能够安全核验物品的地点进行，并完成物品照片、包装、数量、交接码和双方确认。
2. 平台证据采用追加方式保存，历史证据不得由用户覆盖。
3. 站内聊天、支付记录、交接记录、航班证明、海关或航空公司文件、送达照片和双方确认，可在履约核对、内容安全、投诉和争议处理中使用。
4. 用户应避免上传与订单无关的证件信息、他人个人信息或者完整支付凭证；确有必要时应使用平台标明的受限可见渠道。

## 9. 内容管理与平台措施

1. 平台可以依法对需求、行程、报价、聊天和证据内容进行自动或人工安全审核。
2. 对涉嫌禁限物品、虚假申报、站外支付、欺诈、威胁、骚扰、侵犯知识产权或其他违规内容，平台可采取暂缓展示、要求补充、拒绝发布、隐藏内容、限制功能、取消未履行订单或关闭账号等措施。
3. 对用户权益有负面影响的措施，平台应告知主要事实、理由和依据，并提供便捷申诉渠道；用户要求人工复核的，平台应提供人工复核。
4. 紧急风险、执法要求或防止损害扩大时，平台可先采取必要限制，再在合理时间内通知。

## 10. 取消、退款与争议

1. 取消和服务费退款按照《服务费、取消与退款规则》执行。
2. 物品交接后发生的损坏、灭失、延误、税费或通关争议，应提交证据并进入争议流程，不适用无条件自动退款。
3. 平台的内部决定仅用于订单状态、账号措施和平台记录的服务费处理，不替代法院、仲裁机构或行政机关对法律责任的认定。
4. 任何条款均不限制用户依法投诉、举报、请求调解、申请仲裁或提起诉讼的权利。

## 11. 平台责任边界

1. 平台应采取与服务规模相适应的身份、内容、数据和交易安全措施，并依法处理投诉、个人信息请求和安全事件。
2. 平台不对海关、检疫、航空公司、机场、天气、航班变更等独立第三方决定作保证，但应在能力范围内提供已有记录并协助双方使用平台流程。
3. 平台不得通过格式条款免除因其故意或重大过失、违反个人信息保护义务、违法处理支付或依法不得排除的其他责任。
4. 用户的违法、虚假或隐瞒行为造成损失的，应由责任方依法承担；平台有过错的，依法承担与其过错相适应的责任。
5. 任何补偿上限、保险或专项保障计划，必须另行明确公示。在没有明确计划时，平台不得宣传“全额赔付”。

## 12. 暂停、终止与注销

1. 用户可以按照《账号、投诉、申诉与规则变更规则》申请停止使用或注销账号。
2. 未完成订单、进行中争议、依法应保存的交易证据或监管要求可能限制立即删除，但平台应停止非必要处理，并在法定保存期届满后删除或匿名化。
3. 平台终止全部服务的，应依法提前通知，并为用户导出必要订单记录、处理余额和未决争议提供合理安排。

## 13. 协议变更

1. 平台制定或修改规则，应公开征求意见并按适用法律提前公示；一般变更至少提前 7 日，涉及重要权益或修改较多的变更至少提前 15 日。
2. 平台应保留并供用户查看适用法律要求期限内的历史版本。
3. 平台不得把增加用户义务或减损用户权益的修改设为默认同意。
4. 用户不接受重大修改的，可以停止相关服务或申请退出；平台不得设置不合理障碍。
