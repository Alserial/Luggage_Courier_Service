# 中澳路线四阶段合规检查表（法务审核草案）

> 草案版本：`2026-08-22-draft.1`
> 任何“否”或“不确定”均应暂停订单并进入人工审核或取消

## 1. 共同前置检查

在两条路线中都必须确认：

- [ ] 双方均年满 18 周岁并通过所需身份核验；
- [ ] 携带人在出发地、目的地进行有偿帮带具有合法资格和适当工作权；
- [ ] 行程真实且已核验；
- [ ] 物品属于平台正面清单且不命中默认禁止项；
- [ ] 物品名称、材料、成分、数量、价值、重量和用途完整；
- [ ] 需求方有合法来源、所有权或授权；
- [ ] 携带人已亲自开箱检查并知道行李全部内容；
- [ ] 不属于商业批量、货物、货样、广告品、转售或需要专业运输；
- [ ] 已检查出境地、入境地、经停地和航空公司最新规则；
- [ ] 需要的许可和证明已经由主管机关确认有效；
- [ ] 无需通过低报、拆分、藏匿或错误申报才能完成；
- [ ] 已接受对应版本的交易、物品、费用、证据和路线规则。

## 2. 中国 → 澳大利亚

### 阶段 A：中国出境

- [ ] 物品符合中国“合理自用”行李边界；不能确认的已咨询海关；
- [ ] 不属于禁止/限制出境物品；
- [ ] 不属于货物、货样、广告品或商业运输；
- [ ] 不涉及需申报的现金、文物、野生动植物、公共卫生或战略物项；
- [ ] 如需书面申报，已准备真实申报和有效材料；
- [ ] 符合中国机场、民航禁限带目录和实际航空公司规定。

### 阶段 B：澳大利亚入境

- [ ] 携带人理解 Incoming Passenger Card 的全部问题并将真实回答；
- [ ] 已评估该有偿替他人携带是否需要勾选 business/commercial goods；
- [ ] 物品不依赖 AUD 900 额度来掩盖商业或禁限属性；
- [ ] 不含食品、药品/传统药物、动植物、种子、木材、土壤或生物材料；
- [ ] 已查询 ABF prohibited goods 和 DAFF/BICON 最新条件；
- [ ] 不确定时将申报并接受检查，而不是选择不申报；
- [ ] 携带人有权在澳大利亚完成有偿服务和交付。

## 3. 澳大利亚 → 中国

### 阶段 A：澳大利亚出境

- [ ] 携带人在澳大利亚接受订单、交接和收取服务费具有适当工作权；
- [ ] 物品不属于澳大利亚禁止/限制出口或需要 export permit 的货物；
- [ ] 不涉及 CITES、澳大利亚原生动植物、国防/战略物项或文化遗产；
- [ ] 未以他人订单或发票申请携带人本人的 TRS；
- [ ] 符合实际航空公司和澳大利亚航空危险品要求；
- [ ] 如被认定为商业出口，已停止普通旅客行李流程。

### 阶段 B：中国入境

- [ ] 携带人将按中国海关规则如实申报；
- [ ] 已结合本人身份和全部行李计算申报/免税标准，不把订单单独拆分；
- [ ] 不属于货物、货样、广告品或超过合理自用范围；
- [ ] 不含食品、药品、保健品、动植物及制品、生物材料或其他平台禁品；
- [ ] 书籍、礼品、服饰和日用品符合中国进口、内容及知识产权要求；
- [ ] 需要许可证件或货物通关的，已停止平台旅客行李流程；
- [ ] 对不确定物品将选择申报通道并接受海关处理。

## 4. 交接确认模板

双方在交接页应分别主动确认：

### 需求方

- [ ] 我已如实披露物品及全部成分、数量、价值和来源；
- [ ] 我同意携带人开箱检查；
- [ ] 我没有要求低报、藏匿、拆分或虚假申报；
- [ ] 我理解平台审核不等于海关、检疫或航空公司批准；
- [ ] 我已阅读本路线两国附件的当前版本。

### 携带人

- [ ] 我已亲自检查实物并知道行李全部内容；
- [ ] 我已核对出境、入境、经停和航空公司规则；
- [ ] 我具有完成本次有偿服务所需的签证/工作资格；
- [ ] 我会亲自、真实完成边境和航空申报；
- [ ] 如被要求货物申报、许可或专业运输，我将停止履约。

## 5. 起飞前动态复核

建议在航班计划起飞前 24 小时再次确认：

- [ ] 航班、经停地和航空公司未变更；
- [ ] 两国官方规则和 BICON 条件未出现影响本物品的更新；
- [ ] 物品、包装、标签和数量与交接证据一致；
- [ ] 所有许可仍有效且原件/电子文件可出示；
- [ ] 携带人的全部行李未因新增物品超过申报或航空限制；
- [ ] 不存在召回、电池、危险品或临时禁运风险。

## 6. 平台应记录的规则确认

| 场景 | 确认人 | 必需文档 |
|---|---|---|
| 首次登录 | 所有用户 | 用户协议、隐私政策 |
| 发布需求 | 需求方 | 物品规则、出入境附件 |
| 发布行程 | 携带人 | 交易规则、出入境附件、工作权声明 |
| 提交报价 | 携带人 | 费用规则、路线附件 |
| 接受报价 | 需求方 | 交易规则、费用规则、证据争议规则 |
| 交接 | 双方 | 四阶段检查表、重大风险二次确认 |
| 支付 | 需求方 | 金额、退款和支付提供方规则 |
| 争议 | 申请人 | 证据与争议处理规则 |
