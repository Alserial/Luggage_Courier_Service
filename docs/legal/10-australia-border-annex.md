# 澳大利亚进出境、签证与航空合规附件（法务审核草案）

> 草案版本：`2026-08-22-draft.1`
> 适用：澳大利亚作为出境地、入境地或经停地的订单
> Australian rules and BICON conditions change; users must re-check before every trip

## 1. 上线阻断项：携带人的工作权

1. 携带人收取帮带服务费，可能构成在澳大利亚从事有偿工作或提供服务。
2. 澳大利亚内政部门明确提示，Visitor visa 或 ETA 不允许在澳大利亚工作；其他临时签证也可能限制工作类型、工时或自雇活动。
3. 涉及在澳大利亚接受订单、交接、提供服务或收取报酬的携带人，必须先确认本人具有适当工作权并且活动符合签证条件。
4. 平台不得仅凭用户勾选即认定其有工作权。上线前应由澳大利亚律师确定允许的携带人范围和可接受的核验方式。
5. 未完成该法律评估前，澳洲相关路线不得向 Visitor visa/ETA 或工作权不明确的用户开放携带人功能。

建议试点仅开放给：澳大利亚公民、永久居民、符合条件的新西兰公民或能够通过 VEVO/专业意见证明具有适当工作权的其他用户。最终范围由法务确认。

## 2. 澳大利亚入境

### 2.1 Incoming Passenger Card

携带人必须以本人身份真实、完整填写入境旅客卡。现行卡片明确询问的事项包括：

- 禁止或受限制的药物、类固醇、武器、枪械等；
- 超过酒精和烟草限量的物品；
- 海外取得或免税购买、合计价值超过 AUD 900 的一般物品（包括礼物）；
- 用于 business/commercial use 的货物或样品；
- 达到申报标准的现金；
- 肉、禽、鱼、蛋、乳制品、水果和蔬菜；
- 谷物、种子、植物、草药、木制品和传统药物；
- 动物、动物制品、生物材料、土壤和受污染装备。

用户不确定时应选择申报并向 Australian Border Force 或 biosecurity officer 说明真实情况。平台不能替用户回答旅客卡。

### 2.2 有偿携带与商业用途

1. 入境旅客卡会询问 business/commercial use 的货物或样品。
2. ABF 的旅客免税优惠不适用于 commercial goods。
3. Kargo 订单涉及为他人携带并收取服务费，可能影响物品是否被视为个人物品、礼物或商业货物。
4. 用户不得把 AUD 900 旅客额度当作每个订单的自动免税额度，也不得低报或拆分规避申报。
5. 无法确认时，应在出行前书面咨询 ABF/持牌报关专业人士；需要商业进口或正式货物申报的，不使用本平台普通旅客行李流程。

### 2.3 税费

年满 18 周岁的旅客通常可以对符合条件的 general goods 使用最高 AUD 900 的 duty-free concession，但该优惠：

- 按旅客全部相关物品合并计算；
- 不适用于商业货物；
- 不表示禁限物品或生物安全物品可以入境；
- 超额时应申报并由 ABF 计算 duty/GST；
- 会因旅客身份、同行家庭、物品属性和规则变化而不同。

平台 CNY 2000 上限与澳大利亚免税标准相互独立。

### 2.4 生物安全

澳大利亚对食品、动植物、种子、木制品、土壤和动物产品执行严格生物安全要求，具体条件应通过 BICON 查询，并可能要求许可、处理、退运或销毁。

Kargo MVP 对食品、药品/传统药物、保健品、动植物及制品、种子、土壤和相关生物材料实行更严格的默认禁止，不因用户承诺申报而放行。

若实际物品含有未披露的动植物成分或土壤污染，携带人应停止履约；已经到达边境的，应真实申报并听从 biosecurity officer 指示。

### 2.5 禁止和限制进口

药品、类固醇、武器、非法色情内容、毒品、烟草/电子烟、受管制化学品、野生动植物制品和其他物品可能被禁止、限制或要求许可。本平台将其中高风险类别全部排除。ABF 最终决定是否允许进口。

## 3. 澳大利亚出境

### 3.1 出口限制

离境物品仍受澳大利亚出口管制。武器、战略和国防物项、某些药品和化学品、受制裁物品、野生动植物和文化遗产等可能需要许可或禁止出口。

平台正面清单不包含上述物品。若材质或用途触发出口许可，应拒绝订单，不得依赖个人行李例外。

### 3.2 野生动植物和 CITES

澳大利亚原生动植物、CITES 所列物种及其制品可能需要出口或再出口许可；个人行李例外通常要求物品为本人所有且非商业目的。替他人有偿携带不应假设符合例外条件。

本平台禁止皮草、珍稀动物皮革、珊瑚、贝壳、羽毛、骨角、传统药物、原生木材或其他可能涉及野生动植物监管的物品。

### 3.3 TRS 物品

Tourist Refund Scheme 是旅客本人满足条件时申请 GST/WET 退税的政府安排。Kargo 不代理 TRS，不得把他人订单物品或他人发票作为携带人本人的 TRS 申请。已获得 TRS 退款又带回澳大利亚的物品，应按 ABF 要求申报。

## 4. 航空危险品和承运人规则

1. 澳大利亚航空安全和航空公司危险品规则独立适用。
2. Kargo 默认禁止电池、充电宝、液体、粉末、喷雾、压力容器、易燃品、化学品、刀具和性质不明物品。
3. 即使法律允许在特定条件下携带某类危险品，平台也可以采取更严格的正面清单。
4. 携带人必须查看实际航空公司的随身/托运行李规则；航空公司拒绝运输时应停止履约。

## 5. 携带人必须知道行李内容

1. 携带人必须亲自开箱、检查并能够说明全部内容。
2. 不接受陌生人交付的密封包裹、无法识别的药品/食品、无标签物质或与照片不一致的物品。
3. 对旅客卡、ABF、biosecurity officer、安检和航空公司的问题必须真实回答。
4. 不因需求方承担费用而把法定申报责任转移给需求方。

## 6. 异常处理

1. 被要求检查、征税、处理、出口、销毁、扣留或提供许可时，应立即配合。
2. 如规则允许，携带人可以选择主动放弃风险物品；不得为完成订单而虚假陈述。
3. 保留 ABF、DAFF、生物安全、航空公司或其他机关出具的记录，并在平台提交受限证据。
4. 费用和退款按过错、官方决定及平台规则处理，不承诺平台承担全部损失。

## 7. 消费者、隐私和经营合规

如果平台在澳大利亚开展业务，Australian Consumer Law、标准格式合同、公平交易、Privacy Act 1988/Australian Privacy Principles、税务、工作和平台经营义务可能同时适用。运营主体不能仅通过选择中国法律或将自身描述为“撮合工具”来排除强制适用的澳大利亚规则。

上线前应由澳大利亚律师确认：

- 平台是否在澳大利亚 carrying on business；
- 携带人的服务是否构成工作、承揽、零工或其他受监管活动；
- 平台、携带人和需求方的税务、保险和消费者责任；
- 数据从澳大利亚向中国 CloudBase 环境传输的隐私要求；
- 允许的签证/工作权范围和验证方式。

官方入口和核对日期见 `sources.md`。
